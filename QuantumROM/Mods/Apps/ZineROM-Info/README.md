# ZineROM Info system app

This module installs the supplied `ZineROM-Info-3.3.2.apk` as a normal preloaded system application at:

`/system/app/ZineROM-Info/ZineROM-Info.apk`

Package: `com.zinerom.info`

It is intentionally installed as `system/app`, not `priv-app`, because the app does not need privileged platform permissions.
